Почему CSS не может этого сделать?

CSS знает только fit-content, что является шириной самая широкая линия после упаковки. Если абзац переносится на 3 строки и последняя строка короткая, CSS по-прежнему определяет размер контейнера по самой длинной строке. Нет свойства CSS, которое бы говорило: «Найдите самую узкую ширину, которая все еще производит ровно 3 строки». Это требует measuring the text at multiple widths and comparing line counts, что именно и делает Pretext WalkLineRanges() делает, без измерения текста DOM в изменить размер пути. Чистая арифметика, никаких перекомпоновок, мгновенные результаты.
